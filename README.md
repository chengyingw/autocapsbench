# AutoCapsBench

Compiled static distribution of the AutoCapsBench research platform.

This repository contains public website build files, original figure crops with source attribution, and supplementary-video assets. It does not contain source PDFs, credentials, or the private development repository.

Development source revision: `df4e2225c9646c6c7df8fb02e102953af35fd491`.

Figure and video rights remain with their respective rightsholders. See [figure sources](figures/SOURCES.md) and [video sources](videos/SOURCES.md); no blanket open-source licence is applied to third-party research media.

Publish the `main` branch root using GitHub Pages. `.nojekyll` preserves the prebuilt static assets. Hash routes and relative local asset URLs support the project directory.

Release v0.17.0: 18 papers, 231 source-linked COF traces and 40,431 retained image samples. Unit-aware overlays separate time, distance, cycles and figure-specific unknown units; native calibrations, log-scale extraction, controls and pointwise sensitivities remain traceable in CSV/JSON. Missing overlaps stay missing. Original PDFs remain excluded.
